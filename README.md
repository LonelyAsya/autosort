# autosort

Программа для автосортировки медиатеки с телефона. Берёт папки с фото, видео и картинками
(например, синхронизированные с телефона в OneDrive), раскладывает их по папкам, подписывает
тегами, находит дубли и показывает их в окне, похожем на «Фото» на iPhone.

Всё работает локально: картинки никуда не отправляются (кроме необязательного поиска авторов
через SauceNAO, который по умолчанию выключен).

## Что она делает

1. **Делит файлы на типы:** «Камера», «Арты», «Мемы», «Скриншоты» и «На ручной разбор».
   - камера: есть данные камеры (EXIF, метаданные видео);
   - скриншоты: имя `Screenshot_…` или размер ровно как экран телефона;
   - арты: имена с Pixiv / Twitter / бору-сайтов, анимации, а для остального — теги нейросети;
   - если уверенности нет, файл идёт на ручной разбор, а не угадывается.
2. **Ставит теги артам** локальной моделью [WD14](https://huggingface.co/SmilingWolf/wd-swinv2-tagger-v3)
   на видеокарте: что нарисовано, персонажи и вселенные (`saber_(fate)` → вселенная `fate`).
   Для видео и GIF берутся несколько кадров.
3. **Раскладывает арты по категориям** из текстовых файлов с тегами. Приоритет задаётся
   порядком в настройках; остальные подходящие категории записываются в теги.
4. **Ищет авторов** по имени файла (Danbooru, Twitter, Pixiv) и, по желанию, через SauceNAO.
5. **Находит дубли:** точные копии (по хэшу) и похожие (пересжатые, уменьшенные, чуть обрезанные)
   по «отпечатку внешнего вида»; видео сравниваются по нескольким кадрам.
6. **Пишет отчёт** `report.txt`: сколько чего, топ тегов, персонажей, вселенных, авторов, сколько места занимают дубли.

## Правила безопасности

- **Перенос с откатом.** Файлы переносятся, а не копируются, и каждый перенос записан в журнал:
  `autosort undo` возвращает всё обратно.
- **Пробный прогон.** `autosort plan` показывает, что и куда поедет, ничего не трогая.
- **Ничего не удаляется само.** Дубли удаляет только пользователь, и только в корзину.
- **Можно прервать.** Результаты разбора сохраняются после каждого файла; при перезапуске
  уже разобранное пропускается.
- **OneDrive «только в облаке».** Файлы скачиваются по одному месяцу; когда место на диске
  подходит к запасу (`reserve_gb`), обработанные файлы снова становятся «только в облаке».

## Установка (Windows 10/11)

1. Откройте [последний релиз](https://github.com/LonelyAsya/autosort/releases/latest) и скачайте
   **`Autosort-Setup-….exe`**.
2. Запустите его. Права администратора не нужны, на рабочем столе появится иконка **Autosort**.
   Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»
   (программа не подписана платным сертификатом).
   Если по двойному клику вообще ничего не происходит, нажмите на скачанный файл правой кнопкой →
   «Свойства» → поставьте галочку **«Разблокировать»** → «ОК» (или в PowerShell: `Unblock-File путь_к_файлу`).

Нужна версия без установки? Скачайте `Autosort-portable-….zip`, нажмите на него правой кнопкой →
**«Извлечь всё…»** и запускайте `Autosort\Autosort.exe` из распакованной папки. Не запускайте exe прямо
из окна архива: рядом с ним должна лежать папка `_internal`. После двойного клика сначала появляется заставка,
первый запуск может занять до минуты (Windows проверяет библиотеки антивирусом).
Если программа не открылась, посмотрите `%LOCALAPPDATA%\Autosort\crash.log` и `autosort.log`.
Если положить `config.toml` рядом с `Autosort.exe`, настройки и база будут храниться в этой же папке.

ffmpeg уже встроен. Видеокарта задействуется автоматически через DirectML (подходит любая видеокарта
с DirectX 12, в том числе NVIDIA RTX), отдельно ставить CUDA не нужно. Модель тегов (~450 МБ)
скачается при первом разборе артов, дальше программа работает без интернета.

## Удаление

**Пуск → Autosort → «Удалить Autosort»** (или «Параметры → Приложения → Установленные приложения»).
В конце удаления программа спросит, стереть ли настройки, списки тегов, базу и скачанную нейросеть
(`%LOCALAPPDATA%\Autosort`, ~450 МБ модели). Ваши фото и разложенные папки не трогаются в любом случае.
Портативная версия удаляется просто удалением её папки.

## Как пользоваться

Откройте Autosort с иконки:

1. **Папки.** Нажмите «Выбрать…» у «Откуда» (папка OneDrive с папками-месяцами) и у «Куда раскладывать».
2. **Пробный прогон.** Программа разберёт файлы и покажет, что и куда поедет, ничего не перенося.
   Подробный план откроется таблицей.
3. **Разложить.** После подтверждения файлы перенесутся. Если что-то не так,
   «Откатить последний перенос» вернёт всё на место.
4. **Показать дубли** откроет окно разбора в браузере. **Только дубли (вся библиотека)** ищет повторы
   по всей медиатеке без сортировки.
5. **Сделать отчёт** сохранит и откроет `report.txt`.

Можно выбрать один месяц или поставить галочку «Перепроверить уже разобранные» (заново прогоняет
файлы через нейросеть). «Остановить» прерывает работу, всё уже сделанное сохраняется.

После правки списков тегов или порядка категорий нажмите **«Пересчитать категории»**: программа
применит новые правила к тегам, которые уже лежат в базе, без нейросети и без скачивания файлов,
и предложит переложить уже разложенные арты в новые папки (это тоже можно откатить).
Заново прогонять через нейросеть нужно, только если поменялись пороги уверенности в `[tagger]`.

Кнопка **«Настройки…»** открывает `config.toml` в Блокноте, **«Списки тегов…»** — папку с файлами
категорий. После правки нажмите «Перечитать настройки». Всё это хранится в
`%LOCALAPPDATA%\Autosort`, там же база `autosort.db`.

## Командная строка (для любителей)

Тот же функционал есть в виде команд. Для этого нужен Python 3.11+ и ffmpeg в `PATH`:

```bat
git clone https://github.com/LonelyAsya/autosort.git
cd autosort
pip install -e ".[tagger]"
```

Настройки ищутся по порядку: `-c путь`, `local/config.toml`, `config.toml` в текущей папке,
затем `%LOCALAPPDATA%\Autosort\config.toml` (тот же, что у программы с окном).

| Команда | Что делает |
|---|---|
| `autosort scan` | Сканировать: разобрать новые файлы и записать результат в базу, ничего не перенося |
| `autosort plan` | Пробный прогон: то же + сводка и подробный `plan.csv` |
| `autosort sort` | Разложить: разобрать, показать сводку, после подтверждения перенести |
| `autosort dupes` | Показать дубли среди уже разобранных файлов |
| `autosort dupes-only` | Только дубли: отпечатки всей библиотеки без сортировки, затем окно разбора |
| `autosort recategorize` | Пересчитать категории по тегам из базы и переложить разложенное |
| `autosort report` | Сделать отчёт `report.txt` |
| `autosort history` | Список переносов и удалений |
| `autosort undo [--batch N]` | Откатить последний (или указанный) перенос |

У `scan`, `plan`, `sort` есть `--month 2024-05` и `--full` (перепроверить уже разобранные).

## Окно дублей

`autosort dupes` открывает страницу `http://127.0.0.1:8765` (доступна только с этого компьютера).
Группы показаны рядом, зелёной рамкой отмечен файл, который советуем оставить
(больше разрешение → больше вес → старше по дате). Кнопки:
«Оставить эту», «Оставить все» (группа больше не показывается) и
«Удалить лишнее во всех группах» (с подтверждением). Удалённое уходит в корзину.

## Как устроены папки результата

Источник может быть любой вложенности: программа сама обходит все подпапки и обрабатывает
их по одной. Например, если выбрать «Откуда» = `OneDrive/Изображения/Альбом камеры`
(внутри `2024/05/…`), а «Куда» = `OneDrive/Изображения/Отсортированные с телефона`, получится:

```
Отсортированные с телефона/
  Камера/2024/05/IMG_20240501_100000.jpg
  Арты/<категория>/2024/05/98765432_p0.png
  Мемы/2024/05/…
  Скриншоты/2024/05/…
  На ручной разбор/2024/05/…
```

Галочка «Внутри категорий сохранять папки год/месяц» (или `[layout] by_month = false`) убирает
подпапки год/месяц: тогда все файлы лежат прямо в папке категории. Совпадающие имена получают
номер: `IMG (1).jpg`. Исходные папки остаются на месте (пустыми). В выпадающем списке можно
выбрать для обработки целый год или один месяц.

## Настройка категорий

В `config.toml`:

```toml
[categories]
default = "Общее"           # для артов, не попавших ни в одну категорию

[[categories.list]]         # первая по приоритету
name = "Пейзажи"
tags_file = "rules/example_scenery.txt"  # путь от папки с config.toml
```

Файл тегов — один тег на строку, `#` — комментарий. В список можно вписывать и персонажей
(`hatsune_miku`, `saber_(fate)`), тогда получится папка под конкретного персонажа, и вселенные —
то, что у персонажа в скобках (`fate`, `arknights`, `azur_lane`): тогда в папку попадут арты
со всеми узнанными персонажами этой игры или аниме. Вселенная определяется только через персонажа,
поэтому арт, где модель никого не узнала, в такую папку не попадёт. Названия тегов как на Danbooru
(пробелы и подчёркивания равнозначны). Посмотреть, какие теги ставит модель, можно в базе
`autosort.db` (таблица `tags`) любой программой для SQLite, например DB Browser for SQLite.

## Где хранятся данные

`autosort.db` (SQLite) рядом с настройками: файлы, их тип, категория, автор, теги, отпечатки
для дублей и журнал переносов. Миниатюры для окна дублей лежат в `.cache/`.

## Ограничения

- Автора по самой картинке определить нельзя; без подсказки в имени файла и без SauceNAO он «неизвестен».
- Вселенная берётся из имени персонажа в скобках; у персонажей без скобок (`hatsune_miku`) её нет.
- Мемы распознаются осторожно: всё сомнительное идёт на ручной разбор.
- Теги пишутся только в базу, не в сами файлы.
- Если OneDrive не отдаёт файлы («Поставщик облачного файла не работает»), программа останавливается
  и ничего не трогает. Возобновите синхронизацию или перезапустите OneDrive и запустите разбор снова.

## Разработка

```bash
pip install -e ".[dev]"
pytest
```

Сборка exe и установщика идёт автоматически в GitHub Actions (`.github/workflows/build-windows.yml`)
при пуше тега `v*`. Локально на Windows: `pip install ".[tagger]" pyinstaller`, затем
`pyinstaller packaging/autosort.spec`. Иконка генерируется скриптом `packaging/make_icon.py`.
В сборку входит ffmpeg (LGPL) от [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds).
